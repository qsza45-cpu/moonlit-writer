Moonlit Writer — 투명 컴팩트 위젯 1.3

윈도우: MoonlitWriter-Windows-x64.zip을 '모두 압축 풀기' 한 뒤 Moonlit Writer 폴더 안의 Moonlit Writer.exe를 실행하세요.
EXE만 따로 옮기지 말고 폴더 전체를 보관하세요. Windows 10/11 64비트용입니다.
로컬 새 실행본은 MoonlitWriter-Windows/Moonlit Writer v1.3 폴더에도 있습니다.

맥: MoonlitWriter-arm64.zip은 Apple Silicon(M1/M2/M3/M4 등), MoonlitWriter-x64.zip은 Intel 맥용입니다.
Finder에서 압축을 풀고 Moonlit Writer.app을 응용 프로그램 폴더에 옮겨 실행하세요.
서명·공증 전 개인용 버전이라 시스템 설정 > 개인정보 보호 및 보안에서 앱별 실행 허용이 필요할 수 있습니다.
자동 측정은 손쉬운 사용 권한을 허용한 뒤 앱 안의 '감지 확인'을 누르세요. 입력 모니터링을 요청하면 함께 허용하고 재실행하세요.
실제 맥에서의 입력 감지, 권한 흐름과 실행은 미검증입니다.

첫 화면 — 자동 집필 시간
집필 앱이 가장 앞에 있고 타이핑할 때 시간이 자동으로 쌓입니다. 시작 버튼을 누를 필요가 없습니다.
입력 간격이 약 2초 이상 벌어지면 대기합니다. 짧은 입력 간격은 같은 집필 활동으로 계산합니다.
대상 앱에서 벗어나면 누적이 멈춥니다. 기본 대상은 한글, Scrivener, Novella, Word, TextEdit, Pages입니다.
앱 이름 차이로 감지되지 않으면 마지막 화면 '시간을 잴 집필 앱'에 실제 프로세스/앱 이름을 추가하세요.
윈도우는 작업 관리자의 세부 정보에서 .exe를 뺀 이름을 넣으면 됩니다. 맥은 활성 앱 이름으로 비교합니다.
웹 편집기를 쓰면 chrome 또는 msedge 등을 목록에 넣을 수 있지만 해당 브라우저의 모든 탭 입력이 집필 활동으로 집계됩니다.
입력한 문장·키 내용은 기록하거나 외부 전송하지 않고 날짜별 시간만 저장합니다.
글자수는 여전히 직접 입력합니다. 한글 음절 자동 집계는 포함하지 않습니다.
'자동 측정 켜짐/꺼짐' 버튼으로 감지를 잠시 멈출 수 있습니다.

가운데 ‹ ›, 아래 여섯 점, 원 안의 마우스 휠로 화면 전환:
자동 집필 → 집중·휴식 타이머 → 오늘 기록 → 소리 → 시간·크기 설정 → 측정 앱 설정.
집중·휴식 타이머는 별도 수동 기능이고 자동 집필 시간과 따로 저장합니다.
오늘 기록/CSV에는 자동 집필 시간과 수동 집중 시간을 구분합니다.

뚜껑
달 뚜껑을 한 번 누르거나 작은 ⌄ 버튼을 누르면 닫힙니다.
닫힌 컴팩트를 다시 누르면 열립니다.
드래그하면 위치를 옮기고, 클릭하면 열고 닫습니다.
닫힌 상태에서도 자동 집필 측정과 실행 중인 집중 타이머는 계속 동작합니다.
우클릭 메뉴에서도 뚜껑 열기/닫기를 고를 수 있습니다.

크기 조절
시간·크기 설정 화면의 '위젯 크기' 슬라이더.
또는 Ctrl(윈도우) / ⌘(맥)를 누른 채 위젯 위에서 마우스 휠.
또는 우클릭 > 크기 > 60~160%.
크기, 뚜껑 상태, 항상 위 설정은 다음 실행 때도 기억합니다.

기타
우클릭: 항상 위, 최소화, 종료.
마우스를 올리면 뚜껑 오른쪽에 최소화·종료 버튼이 나타납니다.
컴팩트 바깥의 투명 부분은 뒤에 있는 창을 클릭할 수 있습니다.
파란 진행 원은 표시하지 않습니다.
기존 WriterTimer_v3.3 및 data.db는 수정하지 않습니다. 펫·코인은 포함하지 않습니다.

검증
윈도우 실제 실행 파일: 자동 키 입력 감지, 입력 멈춤 시 대기, 대상 외 앱 제외, 여섯 화면 전환, 뚜껑 열고 닫기, 크기 변경, 기록·설정 저장, 집중 타이머와 소리 확인.
자동 시간은 250ms 간격으로 갱신합니다. 기록은 2초마다와 정상 종료 때 저장합니다.

로그인 시 자동 실행
처음 실제 앱을 실행하면 자동 실행이 기본으로 등록됩니다. 다음 로그인 때 위젯과 타이핑 측정이 켜집니다.
설정 화면의 '로그인 시 자동 실행' 체크로 켜고 끕니다. 변경은 즉시 적용됩니다.
앱은 중복 실행되지 않고 이미 실행 중이면 기존 위젯을 보여줍니다.
자동 측정 자체를 꺼 두면 로그인 실행 후에도 그 설정을 유지합니다.
ZIP을 압축 해제한 최종 위치에서 앱을 한 번 실행해야 등록됩니다. 앱을 옮겼다면 새 위치에서 다시 실행하세요.
맥은 응용 프로그램 폴더에 옮긴 뒤 한 번 실행하고, 필요한 입력 감지 권한을 허용하세요.
