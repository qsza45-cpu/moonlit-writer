# Moonlit Writer 1.3 — macOS 설치 안내

## 지원 환경
- macOS 13 Ventura 이상 (Electron 44 기준)
- Apple Silicon(M1·M2·M3·M4)과 Intel 맥 모두 지원 — 하나의 Universal 앱입니다.
- 파일: `WritingTimer_macOS_Universal.zip`

## 설치
1. ZIP을 더블클릭해 압축을 풉니다. `Moonlit Writer.app`이 나옵니다.
2. `Moonlit Writer.app`을 Finder 왼쪽의 **응용 프로그램**으로 끌어다 놓습니다.
3. 응용 프로그램에서 `Moonlit Writer`를 실행합니다.

## 첫 실행 보안 경고 (정상)
이 앱은 Apple 개발자 인증서로 서명·공증되지 않은 개인용 버전입니다(애드혹 서명만 적용).
그래서 처음 열 때 "Apple에서 악성 코드가 없음을 확인할 수 없습니다" 같은 경고가 뜹니다.

1. 경고 창에서 **완료**를 누릅니다.
2. **시스템 설정 → 개인정보 보호 및 보안**으로 갑니다.
3. 아래쪽 보안 항목의 "Moonlit Writer이(가) 차단되었습니다" 옆 **그래도 열기**를 누르고 암호를 입력합니다.
4. 다시 뜨는 창에서 **열기**를 누릅니다. 이후에는 경고 없이 열립니다.

이 앱 하나만 허용하는 방법입니다. Gatekeeper를 끄는 명령(`spctl --master-disable` 등)은 쓰지 마세요.

## 자동 집필 시간 측정 권한
키 입력을 감지하려면 권한이 필요합니다. 입력한 글자·키 내용은 저장하거나 보내지 않고, 날짜별 시간만 저장합니다.

1. 앱 첫 화면에 "맥 손쉬운 사용 권한이 필요해요"가 보이면 **감지 확인**을 누릅니다.
2. **시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용**에서 Moonlit Writer를 켭니다.
3. **입력 모니터링** 허용을 요청하면 함께 켭니다.
4. 앱을 종료했다가 다시 실행합니다.

앱을 새 버전으로 바꾸면 권한을 한 번 더 허용해야 할 수 있습니다(서명이 버전마다 달라서).
기본 측정 대상: 한글, Scrivener, Novella, Word, TextEdit(텍스트 편집기), Pages. 다른 앱은 마지막 화면 '시간을 잴 집필 앱'에 앱 이름을 추가하세요.

## 사용법
화면 구성, 뚜껑, 크기 조절, 로그인 시 자동 실행은 Windows판과 같습니다. 단축키는 Ctrl 대신 ⌘입니다. ⌘Q로 종료합니다.

## 데이터 위치
`~/Library/Application Support/Moonlit Writer/`
- `typing-history.json` — 날짜별 자동 집필 시간
- `widget-preferences.json` — 크기·뚜껑·항상 위 설정
- `Local Storage/` — 타이머·기록·소리 설정

앱을 지워도 이 폴더는 남습니다.

## 알려진 문제 / 미검증
- 실제 키 입력 감지는 GitHub의 macOS 테스트 머신에서 권한을 줄 수 없어 검증하지 못했습니다. 실제 맥에서 권한을 허용한 뒤 집필 앱에 타이핑해 시간이 올라가는지 확인이 필요합니다.
- 화면 잠금·잠자기 이후 복귀, 몇 시간 이상 장시간 측정은 실제 맥에서 검증하지 않았습니다.
- 앱 아이콘은 Electron 기본 아이콘입니다(기존과 동일).

## 문제가 생기면
- 앱이 바로 꺼질 때: 터미널에서 아래를 실행하면 오류 메시지가 보입니다.
  `"/Applications/Moonlit Writer.app/Contents/MacOS/Moonlit Writer"`
- 충돌 기록: **콘솔** 앱 → 충돌 보고서 → `Moonlit Writer`
- "손상되었기 때문에 열 수 없습니다"가 뜨면: ZIP을 다시 내려받아 Finder로 압축을 풀어 주세요(다른 압축 프로그램이 앱 구조를 깨뜨릴 수 있습니다).
